# Study Guide & Assessment Generator

## Overview
A pedagogical study prompt that converts raw notes into organized concept summaries, vocabulary tables, and active-recall quizzes with answer keys.

## Primary Use Cases
- Converting raw class notes into structured exam review materials.
- Generating practice quizzes for active recall study routines.
- Creating standardized study sheets for educators and tutors.

## Framework & Technique
- **Framework:** C-A-R-E Framework (Context, Action, Result, Example).
- **Technique:** Few-Shot Prompting.

## Quick Start
1. Open `prompt.md`.
2. Input Subject, Level, and paste text into `[PASTE LECTURE NOTES HERE]`.
